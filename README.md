# Portafolio: kit de herramientas por rol

Una herramienta práctica para cada rol que puedo asumir en un equipo de producto y datos. Cada una es una página HTML autocontenida: ábrela en el navegador.

| Rol | Herramienta | Qué resuelve |
|---|---|---|
| Científico de datos | [Del problema al modelo](herramientas/problema-a-modelo/index.html) | Traduce un problema de negocio en la ficha de un modelo predictivo: tipo de problema, variable objetivo, métricas, modelo base, variables, validación, riesgos y valor económico. |
| Product Owner | [Backlog del Product Owner](herramientas/product-owner/index.html) | Prioriza el backlog con RICE o WSJF contra la capacidad del release y convierte cada pedido en una historia de usuario con criterios Dado/Cuando/Entonces y revisión INVEST. |
