# Portafolio de ciencia de datos

Herramientas y proyectos para llevar problemas de negocio a soluciones analíticas.

## Herramientas

| Herramienta | Qué hace |
|---|---|
| [Del problema al modelo](herramientas/problema-a-modelo/index.html) | Traduce un problema de negocio en la ficha de un modelo predictivo: tipo de problema, variable objetivo, métricas, modelo base, variables candidatas, validación, riesgos y valor económico. Abre el archivo en un navegador. |
